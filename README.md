# Aperçu indépendant — Metz Bureautique

Cette branche contient uniquement une prévisualisation statique de la proposition graphique, composée de 15 pages. Elle ne remplace pas le site WordPress en production.

Les ressources et liens internes sont adaptés au préfixe `/Metz-Bureautique-/` de GitHub Pages. Les sources de la proposition restent inchangées. Les contenus, métadonnées et canoniques d’origine sont conservés ; une directive de non-indexation est ajoutée uniquement à cet aperçu public.

Les formulaires sont démonstratifs et ne transmettent aucune demande. Aucun identifiant ni secret n’est inclus. Les liens externes et les coordonnées publiques d’origine sont conservés.

Publication prévue : GitHub Pages, depuis la racine de cette branche dédiée. Aucune configuration Pages déjà existante ne doit être remplacée.
